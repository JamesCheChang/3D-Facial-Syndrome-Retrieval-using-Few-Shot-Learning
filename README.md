# 3D Facial Syndrome Retrieval using Few Shot Learning
Machine learning can link facial features to underlying syndromes, but 2D methods are limited by their representation, while existing 3D supervised methods struggle to recognize syndromes absent from training data. We developed a few-shot learning framework using 3D facial point clouds to recognize unseen syndromes from limited examples. PointNet++ was used to learn hierarchical geometric features. We compared facial-template, Farthest Point Sampling (FPS), Voxel Grid Sampling, and Curvature Threshold Sampling approaches. Models were evaluated under 5-way and 10-way classification across different shot settings. Accuracy increased with more training examples, with 5-way classification substantially outperforming 10-way classification. FPS and Curvature achieved similar performance, while Voxel performed substantially worse. These results highlight the importance of point-selection strategy, training examples, and class count for few-shot recognition of rare and unseen syndromes.
